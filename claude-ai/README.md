# claude.ai examples

**English.** An example coach built on this MCP: project instructions for a running and strength coach, plus a `graficas` (charts) skill. They're a starting point: copy them and adapt them to your sport, goals and rules.

- [`en/project-instructions.md`](en/project-instructions.md): paste into your claude.ai project's instructions.
- [`en/skills/graficas/`](en/skills/graficas/): upload the folder as a skill.

**Español.** Un entrenador de ejemplo montado sobre este MCP: instrucciones de proyecto para un entrenador de carrera y fuerza y una skill de gráficas, `graficas`. Son un punto de partida: cópialos y adáptalos a tu deporte, tus objetivos y tus reglas.

- [`es/instrucciones-proyecto.md`](es/instrucciones-proyecto.md): pégalas en las instrucciones de tu proyecto de claude.ai.
- [`es/skills/graficas/`](es/skills/graficas/): sube la carpeta como skill.
